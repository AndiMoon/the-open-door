# The Open Door

A magazine-style site of business book summaries and links. This starter uses Next.js, MDX, and Tailwind CSS.

## What I scaffolded

- Next.js pages
- MDX content in content/books (3 placeholder books)
- Tailwind CSS
- Client-side search (Fuse.js) and tag filtering
- Affiliate disclosure footer

## Local development

1. Install dependencies

   npm install

2. Run in dev mode

   npm run dev

Open http://localhost:3000

## Deploy to Vercel

1. Go to https://vercel.com/new and import the GitHub repository (AndiMoon/the-open-door).
2. Vercel will detect Next.js — click Deploy.
3. (Optional) Connect your custom domain in the Vercel dashboard.
